# Working rules for this repo

- **Language: English only.** All commits, docs, code comments, public posts,
  and web content are written in English — never Indonesian.
- **Public repo is canonical:** `github.com/Tgentic/TGENTIC` is the public,
  open-source repository. The local remote `origin` is the private deployment
  repo (Railway/mainnet ops) — token/market material (e.g. the CA in
  `web/src/links.js`) stays here and is intentionally kept out of the public
  framework repo.
- Claims in docs/posts must be verifiable on chain or in the repo; "done"
  means verifiable, not announced (see `ROADMAP.md` and `CHANGELOG.md`).
