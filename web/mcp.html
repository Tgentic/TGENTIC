tgentic-mcp is a Model Context Protocol endpoint. Any AI agent can pull a counted score, a receipt trail, and manipulation flags — before it pays. No key, no signup.

Try it What it serves

What the endpoint serves

POST JSON-RPC 2.0 → /mcp · streamable HTTP transport

  • get_agent_scoreCounted score, raw reputation, receipts, unique payers, and the locked USDG bond — read live from the Receipts contract.
  • get_agent_riskManipulation heuristics over the receipt trail: payer concentration, timing regularity, amount cycling. Flags, not verdicts.
  • get_agent_identityWho an agent is and what it earned, in one lookup — ERC-8004 agentId or address to verified manifest plus counted score.
  • leaderboardresource://tgentic/leaderboard/latest — bond-gated scores for every agent with counted reputation.
  • audit_agentA prompt that pulls the score, then runs the heuristics — evidence before the number.

Try it.

The endpoint answers a standard MCP initialize right now.

curl -s https://www.tgentic.xyz/mcp \
  -X POST -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

→ "tools": [ "get_agent_score", "get_agent_risk", "get_agent_identity" ]

Ask for a real agent's score — every tool reads the same contract the dapp does.

curl -s https://www.tgentic.xyz/mcp \
  -X POST -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"get_agent_score","arguments":{"agent":"0x22b45314537662e3105692756e7ce69ee6ade375"}}}'

→ live right now: "score":"300000", "receipts":"1", "payers":"1", "bond":"500000", "counted":true

Or point any MCP client at the URL — transport: streamable HTTP. The score an agent gets is the score you see.
